06 · Technology

The recommended stack

LayerChoiceWhy it's right here
POS & admin apps React PWA (installable web app) One codebase runs on Android tablets, iPads, phones, and desktops. No app stores, instant updates.
Local server Raspberry Pi 4, 4 GB + PocketBase (SQLite) A silent, palm-sized computer serving the whole shop. One lightweight open-source package provides the database, sign-in, file storage, and live updates.
Cloud server Small VPS (DigitalOcean / Hetzner) Flat ~₱500/month, no per-transaction fees. Holds the synced copy, backups, and remote admin access.
Sync engine Queue-based sync service Pushes sales and stock movements up; pulls menu, price, and staff changes down. Automatic every few minutes, plus a manual "Sync now" button.
Backups Nightly encrypted off-site backups The shop's data survives fire, theft, or hardware failure.

Why not just Firebase?

Firebase is a strong platform and we evaluated it first. It falls short on this project's core requirement: true offline operation across multiple devices. Firebase's offline mode is per-device — two tablets can't agree on stock levels without internet, sign-in requires connectivity, and it can't run on the shop's own server. Its costs also scale with every read and write. The recommended stack keeps what makes Firebase attractive — one place for data, sign-in, and files — but runs it on hardware you own, with a flat, predictable cloud bill.
